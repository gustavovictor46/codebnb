## Requisitos

### 1.1 Requisitos Funcionais do Sistema


| ID | Requisito | Descrição |
| --- | --- | --- |
| RF01 | Realizar Login | O sistema deve permitir que o usuário acesse sua conta por meio de autenticação. |
| RF02 | Exibir Tela Principal | O sistema deve apresentar a página inicial com os principais conteúdos da plataforma. |
| RF03 | Cadastrar | O sistema deve possibilitar que novos usuários realizem seu cadastro na plataforma. |
| RF04 | Consultar | O usuário deve poder pesquisar e visualizar registros de clientes, imóveis e aluguéis. |
| RF05 | Atualizar | O usuário deve poder editar e salvar alterações em registros já existentes. |
| RF06 | Excluir | O usuário deve poder remover registros cadastrados anteriormente no sistema. |
| RF07 | Encerrar Sessão | O usuário deve poder sair de sua conta de forma segura (logout). |
